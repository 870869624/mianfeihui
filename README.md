# 原创圈 · 官网 — 使用与部署文档

> 古风原创绘画头像社区官网 · 纯静态单页（HTML + CSS + JS）
> 无需数据库、无需后端，上传即可使用。


## 二、★ 配置蓝奏云下载链接（上线前必做）

下载链接 **只需改一处**：打开 `assets/js/main.js`，文件最上方：

```js
const DOWNLOAD_LINKS = {
  ios:     "",   // ← 在此粘贴蓝奏云 iOS 安装包分享链接
  android: "",   // ← 在此粘贴蓝奏云安卓安装包分享链接
};
```

把两个空字符串替换为你的蓝奏云分享链接，例如：

```js
const DOWNLOAD_LINKS = {
  ios:     "https://wwoop.lanzouq.com/b0123abcd",
  android: "https://wwoop.lanzouq.com/b0456efgh",
};
```

保存后页面底部「iOS 端下载」「安卓端下载」两个按钮即会自动跳转到对应链接（新标签页打开）。

**说明：**
- **链接未填写时**，两个下载按钮会自动置灰（半透明），访客点击会弹出提示「下载链接尚未配置」，不会误跳转；填好链接并刷新后按钮恢复常态。
- 建议在蓝奏云分享设置中**不要设提取码**（或把提取码附在提示文案里），访客点击即可直达。
- 蓝奏云分享域名可能因政策调整（如 `lanzouq` / `lanzouv` 等后缀变化），以你分享页实际域名为准。
- 若日后想改为直接指向 App Store / 应用市场，同样只改这两行即可。

## 三、常用修改指南

### 3.1 改文案（站名、数据、承诺等）

全部在 `index.html` 中直接搜索修改：

| 想改什么 | 搜索位置 |
|---|---|
| 站名「原创圈」 | `index.html` 中的 `brand-text`、`<title>` |
| 数据（120+ 博主 / 300+ 群组 / 5万+ 同好） | `stats-grid` 一节 |
| FAQ 问答内容 | `faq-list` 一节，每条是一个 `<details>` |
| 进群三步说明 | `steps` 一节 |
| 页脚邮箱与备案号 | `footer-contact`（备案号目前为占位，上线前务必替换为真实备案号或删除） |

### 3.2 换图片

直接用同名文件覆盖 `assets/images/` 下的图片即可：

- `hero.jpg` — 首屏主视觉（建议横版 ≥1536px 宽）
- `work-1.jpg` ~ `work-4.jpg` — 作品长廊（建议正方形或近方形，≥900px）

若想增删作品图，在 `index.html` 的 `gallery-grid` 中复制/删除一个 `<figure class="gallery-item">` 块，并修改 `<img src>` 与图注即可。

> 图片建议压缩后再上传（每张 300KB 内最佳），可用 [squoosh.cn](https://squoosh.cn) 在线压缩。

### 3.3 改配色 / 字体

打开 `assets/css/style.css`，顶部 `:root` 变量集中管理：

```css
--paper:     #F6F1E7;  /* 宣纸底色 */
--ink:       #2B241A;  /* 墨色文字 */
--cinnabar:  #A93B2A;  /* 朱砂主色（按钮/印章） */
--azurite:   #3E6862;  /* 石青点缀 */
```

## 四、本地预览

方式一（最简单）：直接双击 `index.html` 用浏览器打开。

方式二（推荐，行为与线上一致）：在本目录启动静态服务器：

```bash
# 有 Python 环境
python -m http.server 8080

# 或有 Node 环境
npx serve .
```

然后浏览器访问 `http://localhost:8080`。

## 五、部署上线

本站为**纯静态页面**，任何支持静态托管的服务均可部署，任选其一：

### 方式 A：宝塔面板 / 云服务器（有自己服务器时）

1. 将整个项目文件夹（含 `assets`）上传至站点根目录，如 `/www/wwwroot/ycc.quan/`；
2. 宝塔「网站」中新建站点指向该目录，绑定域名；
3. 建议在宝塔中一键申请免费 SSL 证书（HTTPS）。

### 方式 B：腾讯云 COS / 阿里云 OSS 静态托管

1. 创建存储桶，将 `index.html` 与 `assets/` 全部上传；
2. 开启「静态网站」功能，索引文档填 `index.html`；
3. 绑定自定义域名（国内需已备案域名）。

### 方式 C：Vercel / Netlify / GitHub Pages（境外托管，免服务器）

- **Vercel**：登录 [vercel.com](https://vercel.com) → Add New Project → 直接拖入项目文件夹即可获得访问地址；
- **GitHub Pages**：新建仓库上传文件 → Settings → Pages → 选择分支根目录。

> ⚠️ 提示：境内访问 Vercel/GitHub Pages 速度不稳定。面向国内用户、需要备案域名的正式站点，建议优先选择方式 A 或 B。

### 上线检查清单

- [ ] 已在 `main.js` 填入两个蓝奏云下载链接，点击按钮可正常跳转
- [ ] 已替换页脚备案号（国内服务器/CDN 必须）与联系邮箱

- [ ] 数据（博主数、群组数等）已改为真实数字
- [ ] 手机端打开检查一遍（本站已做响应式适配）

## 六、常见问题

**Q：点击下载按钮没反应？**
A：说明 `main.js` 里的链接还没填。按第二节填写后刷新页面。

**Q：蓝奏云链接提示「文件取消分享」？**
A：到蓝奏云后台检查文件分享状态，重新生成分享链接并更新 `main.js`。

**Q：想加百度统计 / CNZZ 怎么办？**
A：把统计代码粘贴到 `index.html` 的 `</body>` 之前即可。

**Q：如何更换首页字体？**
A：当前使用系统自带宋体/楷体栈（零加载成本）。如需网络字体（如思源宋体全量字重），在 `style.css` 顶部 `@import` 或 `index.html` 中引入字体 CSS，并修改 `--serif` / `--kai` 变量。注意中文字体文件较大，建议使用字体子集化服务。
